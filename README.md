# Projeto-SQL-Reserva-de-carros

## Sobre o projeto
Projeto de banco de dados desenvolvido para gerenciar um sistema de reserva de veículos, incluindo clientes, carros, classes e sedes, ele 
consiste na modelagem e implementação de um banco de dados relacional para esse sistema de reservas.

O sistema permite:

* Cadastro de clientes
* Cadastro de veículos
* Organização por classes de carros
* Controle de sedes 
* Registro de reservas

## Estrutura do Banco de Dados

O banco de dados é composto pelas seguintes tabelas:

* clientes 
* carros 
* classes_carro 
* sedes 
* reservas 

## Tecnologias utilizadas

* SQL
* MySQL 
* phpMyAdmin

## Como executar o projeto
1. Abra o MySQL ou phpMyAdmin
2. Crie um banco de dados
3. Importe ou execute o arquivo `sistema reserva carro.sql`
4. As tabelas e relacionamentos serão criados automaticamente.
